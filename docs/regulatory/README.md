# Regulatory folder

Put official regulatory texts here (PDF, Word, Markdown or text). The
assistant reads them on this machine, cites file and page, and compares them
with QDB's settings. Files here are not uploaded and not committed to git
(see `.gitignore`); only this README is.

Sub-folders are fine, for example:

    docs/regulatory/QCB/Circular 9-2017 IFRS 9 instructions.pdf
    docs/regulatory/Basel/CRE22.pdf
    docs/regulatory/EBA/2025 EU-wide stress test - Methodological Note.pdf

A scanned PDF needs a text layer (OCR) before it can be searched.

## Recommended documents

| Document | Where to get it |
|---|---|
| QCB Circular 9/2017 — IFRS 9 instructions to banks (with any later amendments) | QDB's copy from QCB (Compliance / Finance) |
| QCB Instructions to banks — credit risk, collateral, classification of facilities, ICAAP and stress testing | https://www.qcb.gov.qa (Instructions to banks) |
| IFRS 9 Financial Instruments (impairment, section 5.5 and Appendix B) | IFRS Foundation (registered access), or the EU-endorsed text, Commission Regulation (EU) 2016/2067: https://www.legislation.gov.uk/eur/2016/2067 |
| Basel Framework — CRE20, CRE22, CRE32, CRE36 | https://www.bis.org/basel_framework/ (each chapter has a PDF) |
| Basel Committee — Stress testing principles (2018, d450) | https://www.bis.org/bcbs/publ/d450.htm |
| EBA — Guidelines on credit institutions' credit risk management practices and accounting for expected credit losses (EBA/GL/2017/06) | https://www.eba.europa.eu |
| EBA — 2025 EU-wide stress test, Methodological Note | https://www.eba.europa.eu |
| Bank of England — Key elements of the 2025 Bank Capital Stress Test; Guidance for participants | https://www.bankofengland.co.uk/stress-testing |
| Federal Reserve — 2026 Supervisory Stress Test Methodology; 2026 scenarios | https://www.federalreserve.gov/supervisionreg/stress-tests-capital-planning.htm |
| FINMA — stress tests; circulars on credit risk | https://www.finma.ch |
